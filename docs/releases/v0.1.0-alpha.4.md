# NO-GO / DO NOT USE — v0.1.0-alpha.4

This build repairs alpha.3's partial-runner state and makes the Expedition 33 action visible, but target-device testing exposed a later one-tap failure: Steam navigates to the hidden runner shortcut page after the action is pressed and alpha.4 does not suppress that automatic detour. Use `v0.1.0-alpha.5` or newer.

## Download and install

Install the release asset through **Decky Settings → Install Plugin from URL**:

```text
https://github.com/AutonomousWork/stream-gfn/releases/download/v0.1.0-alpha.4/stream-gfn-v0.1.0-alpha.4.zip
```

The release also provides `stream-gfn-v0.1.0-alpha.4.zip.sha256`. Do **not** use GitHub's generated **Source code (zip)**; it is not the packaged Decky plugin. The Desktop Mode fallback extracts the named asset's one `stream-gfn/` directory to `~/homebrew/plugins/stream-gfn`.

## What changed from alpha.3

- Creates the reusable shortcut with Steam's stable empty directory and option placeholders, then applies and verifies the exact runner fields after Steam publishes it.
- Repairs one uniquely plugin-owned partial runner in place when its name, executable, type, and safe remaining fields prove ownership; ambiguous, foreign, or duplicate matches remain untouched.
- Anchors the Expedition 33 action immediately before Steam's current app-panel wrapper, matching the live library shape used by the working HLTB panel on the target device.
- Treats a missing current action anchor as an explicit compatibility failure instead of silently appending the action at the end of the page.

## Validation boundary

The panel must report `GeForce NOW: Ready`, `Runner: Inactive`, and the packaged `v0.1.0-alpha.4` build identity. Expedition 33 does not need to be installed; its normal library page must retain the native **Install** action and show one **Stream on GeForce NOW** action. Stable promotion remains blocked until the [Legion Go S device-proof checklist](https://github.com/AutonomousWork/stream-gfn/blob/v0.1.0-alpha.4/docs/device-proof.md) records both complete one-tap lifecycle cycles, controller and overlay behavior, Steam-owned exit, constant runner footprint, and the unsupported-AppID fail-closed check.

If a route, identity, ownership, lifecycle, or one-tap gate fails, the release remains `NO-GO / DO NOT USE`; it must not be promoted to stable. Before uninstalling, remove the hidden runner only through the plugin's explicit cleanup action while the runner is verified inactive.

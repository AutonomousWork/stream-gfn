# UNVALIDATED DEVICE BUILD — v0.1.0-alpha.1

**UNVALIDATED DEVICE BUILD:** this prerelease is browser-accessible for Legion Go S testing, but it has not yet passed the target-hardware proof. Do not treat it as stable or expand it to additional titles until the recorded proof passes.

## Download and install

Install the release asset through **Decky Settings → Install Plugin from URL**:

```text
https://github.com/AutonomousWork/stream-gfn/releases/download/v0.1.0-alpha.1/stream-gfn-v0.1.0-alpha.1.zip
```

The release also provides `stream-gfn-v0.1.0-alpha.1.zip.sha256`. Do **not** use GitHub's generated **Source code (zip)**; it is not the packaged Decky plugin. The Desktop Mode fallback extracts the named asset's one `stream-gfn/` directory to `~/homebrew/plugins/stream-gfn`.

## What this build contains

- One-tap **Stream on GeForce NOW** action on the normal *Clair Obscur: Expedition 33* Steam page.
- Strict support for Steam AppID `1903340` only.
- One reusable hidden `Stream GFN Runner`, with full ownership verification and no per-title shortcut sprawl.
- Fixed-route launch through the GeForce NOW Flatpak, including cold starts.
- Explicit compatibility, activity, build-identity, and verified-cleanup states in the plugin panel.

## Validation boundary

Browser download proves transport only. Stable promotion remains blocked until the [Legion Go S device-proof checklist](https://github.com/AutonomousWork/stream-gfn/blob/v0.1.0-alpha.1/docs/device-proof.md) records both complete one-tap lifecycle cycles, controller and overlay behavior, Steam-owned exit, constant runner footprint, and the unsupported-AppID fail-closed check.

If a route, identity, ownership, lifecycle, or one-tap gate fails, the release must be marked `NO-GO / DO NOT USE`; the plugin must not be promoted to stable. Before uninstalling, remove the hidden runner only through the plugin's explicit cleanup action while the runner is verified inactive.

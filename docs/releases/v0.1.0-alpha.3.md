# UNVALIDATED DEVICE BUILD — v0.1.0-alpha.3

**UNVALIDATED DEVICE BUILD:** this prerelease fixes alpha.2's Decky-only Flatpak preflight failure and is browser-accessible for Legion Go S testing, but it has not yet passed the complete target-hardware proof. Do not treat it as stable or expand it to additional titles until the recorded proof passes.

## Download and install

Install the release asset through **Decky Settings → Install Plugin from URL**:

```text
https://github.com/AutonomousWork/stream-gfn/releases/download/v0.1.0-alpha.3/stream-gfn-v0.1.0-alpha.3.zip
```

The release also provides `stream-gfn-v0.1.0-alpha.3.zip.sha256`. Do **not** use GitHub's generated **Source code (zip)**; it is not the packaged Decky plugin. The Desktop Mode fallback extracts the named asset's one `stream-gfn/` directory to `~/homebrew/plugins/stream-gfn`.

## What changed from alpha.2

- Restores the host `LD_LIBRARY_PATH` before Decky's PyInstaller-hosted backend launches the system Flatpak executable.
- Preserves the remaining Deck session environment, including user-install discovery through `HOME` and `USER`.
- Adds regression coverage for both a saved original library path and a host with no original path.
- Keeps the one-tap Expedition 33 flow, fixed route, and one reusable hidden runner unchanged.

## Validation boundary

The panel must report `GeForce NOW: Ready` and the packaged `v0.1.0-alpha.3` build identity before the library action is tested. Stable promotion remains blocked until the [Legion Go S device-proof checklist](https://github.com/AutonomousWork/stream-gfn/blob/v0.1.0-alpha.3/docs/device-proof.md) records both complete one-tap lifecycle cycles, controller and overlay behavior, Steam-owned exit, constant runner footprint, and the unsupported-AppID fail-closed check.

If a route, identity, ownership, lifecycle, or one-tap gate fails, the release remains `NO-GO / DO NOT USE`; it must not be promoted to stable. Before uninstalling, remove the hidden runner only through the plugin's explicit cleanup action while the runner is verified inactive.

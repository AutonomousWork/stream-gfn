# UNVALIDATED DEVICE BUILD — v0.1.0-alpha.5

**UNVALIDATED DEVICE BUILD:** this prerelease fixes alpha.4's automatic detour to the hidden runner shortcut page. It is browser-accessible for Legion Go S testing, but it has not yet passed the complete target-hardware proof. Do not treat it as stable or expand it to additional titles until the recorded proof passes.

## Download and install

Install the release asset through **Decky Settings → Install Plugin from URL**:

```text
https://github.com/AutonomousWork/stream-gfn/releases/download/v0.1.0-alpha.5/stream-gfn-v0.1.0-alpha.5.zip
```

The release also provides `stream-gfn-v0.1.0-alpha.5.zip.sha256`. Do **not** use GitHub's generated **Source code (zip)**; it is not the packaged Decky plugin. The Desktop Mode fallback extracts the named asset's one `stream-gfn/` directory to `~/homebrew/plugins/stream-gfn`.

## What changed from alpha.4

- Arms a short-lived redirect token immediately before Steam receives the hidden runner launch.
- Returns from Steam's automatic runner shortcut page exactly once when its AppID matches that pending launch.
- Leaves ordinary library navigation, unsupported AppIDs, expired launch tokens, and subsequent runner-page renders untouched.
- Retains alpha.4's repaired reusable runner and current Expedition 33 library-action anchor.

## Validation boundary

The panel must report `GeForce NOW: Ready`, `Runner: Inactive`, and the packaged `v0.1.0-alpha.5` build identity before launch. Expedition 33 does not need to be installed; its normal library page must retain the native **Install** action and show one **Stream on GeForce NOW** action. After one activation, Steam must not remain on the hidden runner shortcut page, and GFN must reach title-identifying Expedition 33 allocation or queue without another Play action. Stable promotion remains blocked until the [Legion Go S device-proof checklist](https://github.com/AutonomousWork/stream-gfn/blob/v0.1.0-alpha.5/docs/device-proof.md) records both complete one-tap lifecycle cycles, controller and overlay behavior, Steam-owned exit, constant runner footprint, and the unsupported-AppID fail-closed check.

If a route, identity, ownership, lifecycle, or one-tap gate fails, the release remains `NO-GO / DO NOT USE`; it must not be promoted to stable. Before uninstalling, remove the hidden runner only through the plugin's explicit cleanup action while the runner is verified inactive.

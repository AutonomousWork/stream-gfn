# NO-GO / DO NOT USE — v0.1.0-alpha.2

This build fixes alpha.1's backend startup failure, but its Flatpak preflight inherits Decky Loader's bundled library path. On the target device, `/usr/bin/flatpak info com.nvidia.geforcenow` succeeds in Konsole and fails only inside the plugin backend. Use `v0.1.0-alpha.3` or newer.

## Download and install

Install the release asset through **Decky Settings → Install Plugin from URL**:

```text
https://github.com/AutonomousWork/stream-gfn/releases/download/v0.1.0-alpha.2/stream-gfn-v0.1.0-alpha.2.zip
```

The release also provides `stream-gfn-v0.1.0-alpha.2.zip.sha256`. Do **not** use GitHub's generated **Source code (zip)**; it is not the packaged Decky plugin. The Desktop Mode fallback extracts the named asset's one `stream-gfn/` directory to `~/homebrew/plugins/stream-gfn`.

## What changed from alpha.1

- Moved the Python backend into Decky's supported `py_modules/` import path.
- Added a release smoke test that loads `main.py` the same way Decky does, from outside the plugin directory.
- Kept the one-tap Expedition 33 flow, fixed route, and one reusable hidden runner unchanged.

## Validation boundary

The panel must leave its initial checking state and report the packaged `v0.1.0-alpha.2` build identity before the library action is tested. Stable promotion remains blocked until the [Legion Go S device-proof checklist](https://github.com/AutonomousWork/stream-gfn/blob/v0.1.0-alpha.2/docs/device-proof.md) records both complete one-tap lifecycle cycles, controller and overlay behavior, Steam-owned exit, constant runner footprint, and the unsupported-AppID fail-closed check.

If a route, identity, ownership, lifecycle, or one-tap gate fails, the release remains `NO-GO / DO NOT USE`; it must not be promoted to stable. Before uninstalling, remove the hidden runner only through the plugin's explicit cleanup action while the runner is verified inactive.
